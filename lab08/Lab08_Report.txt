1. Disk Scheduling (Phase 2):

The SCAN algorithm had a lower total head movement than FCFS because it moved the disk head in one direction first and serviced the requests along the way before reversing direction. In my experiment, FCFS had a total head movement of 640 cylinders, while SCAN had only 331 cylinders. FCFS followed the requests exactly in the order they arrived, so the disk head moved back and forth many times. SCAN behaved like an elevator, which reduced unnecessary movement and made disk access more efficient.

2. I/O Bound Concept:

An I/O Bound system means that the program spends a lot of time waiting for input or output operations, such as reading data from or writing data to storage. During this waiting time, the CPU is not always running at 100% usage. It can be mostly idle because it has to wait for the I/O operation to finish before continuing the task. Therefore, the performance is limited more by storage speed than by CPU speed.

3. AI Industry Connection (Phase 3):

Storing an AI image dataset as many separate files causes high I/O overhead because the Operating System must repeatedly open files, read metadata, check permissions, read the data, and close each file. In my experiment, reading 1,000 separate small files took 0.0164 seconds, while reading one packed file took only 0.0006 seconds. Packing the data into one large sequential file reduces the number of file operations and allows the system to read data more continuously. This helps reduce I/O overhead and prevents the GPU from waiting too long for data.
