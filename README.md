## About This Repository

This repository contains Operating Systems laboratory exercises from Lab 6 to Lab 10.

The laboratories focus on important Operating System concepts such as:

- Virtual Memory
- Page Replacement
- Thrashing
- CPU Scheduling
- Disk Scheduling
- I/O Management
- File Systems
- File Permissions
- Concurrency
- Deadlock Avoidance
- Resource Management

The final lab combines these concepts into a simulated AI Cluster Operating System.
